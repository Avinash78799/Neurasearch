# Release Notes — NeuraSearch v1.0.0

NeuraSearch v1.0.0 is the first stable, production-ready release of the AI-powered Knowledge Operating System and multi-agent RAG search assistant.

---

## Key Features

1. **Workspace Isolation**: Enforces strict workspace bounds for notes, documents, pages, collections, and vector search embeddings.
2. **Hybrid & Universal Retrieval**: Combines SQLite, BM25 indices, and ChromaDB vector embeddings with FlashRank reranking and tavily web search fallbacks.
3. **Structured Document Reader**: A premium split pane layout (Left: document page loader; Right: AI chat assistant, highlights, and connections).
4. **Resilient Production Backups**: Includes online SQLite backups and workspace JSON imports/exports.
5. **Polished Design & Motion**: Built using outfit typography, customized HSL styling variables, loading skeletons, and accessibility keyboard navigation.
